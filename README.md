# Django Developer Portfolio

A personal, production-ready portfolio built with **Django** to showcase projects, professional experience, and technical background. The application is modular, database-driven, and designed with scalability and clean architecture in mind.

---

## 🔍 Overview

This portfolio demonstrates:

* Full-stack Django development
* Modular app architecture
* Dynamic content rendering from a database
* Admin-managed content (projects & experience)
* Clean UI with reusable templates

It is intended both as a **professional showcase** and as a **reference Django project**.

---

## 🧱 Project Structure

```
django-portfolio/
├── blog/            # Blog posts (future expansion)
├── core/            # Project settings & root URLs
├── experience/      # Professional experience timeline
├── main/            # Home page
├── projects/        # Portfolio projects
├── media/           # Uploaded images
├── static/          # CSS, JS, images
├── templates/       # Base & app templates
├── db.sqlite3
├── manage.py
└── venv/
```

## 🚀 Setup Instructions

### 1. Clone the Repository

```bash
git clone https://github.com/your-username/django-portfolio.git
cd django-portfolio
```

### 2. Create & Activate Virtual Environment

```bash
python -m venv venv
venv\Scripts\activate
```

### 3. Install Dependencies

```bash
pip install django
```

### 4. Apply Migrations

```bash
python manage.py migrate
```

### 5. Create Superuser

```bash
python manage.py createsuperuser
```

### 6. Run Development Server

```bash
python manage.py runserver
```

Open: [http://127.0.0.1:8000/](http://127.0.0.1:8000/)

---

## 🗂️ Admin Access

```text
/admin/
```

Use the superuser credentials created earlier to manage content.
